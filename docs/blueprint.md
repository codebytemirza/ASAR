# **App Name**: ASAR Systech Portfolio

## Core Features:

- Home Page Showcase: Display key metrics, services, and industries served with a clear call-to-action.
- Services Page: Detailed view of ISO consultancy and AI automation services with technologies used.
- Technology Grid: Showcase the company's technology stack categorized into AI & ML, Backend & Cloud, Security & SIEM, and Frontend.
- About Page: Describe the industries served with specific use case examples to highlight expertise.
- Contact Form: Implement a contact form with fields for name, email, company, and a dropdown for service interest.
- Responsive Design: Ensure the website is fully functional and visually appealing on all devices using responsive design principles.
- Scroll Animations: Implement subtle fade-in and slide-up animations for elements as the user scrolls, enhancing user experience.
- AI Consultancy: AI and Automation services with technologies used

## Style Guidelines:

- Primary accent color: Medium blue/purple (#7C8CFF) for highlights, buttons, and borders. Evokes trustworthiness.
- Primary background color: White (#FFFFFF) for a clean, professional look.
- Secondary background color: Very light blue (#EEF1FF) to break up the white space. Retains a feeling of coolness.
- Font: 'Inter' sans-serif for all text, to project a neutral and objective feeling. Note: currently only Google Fonts are supported.
- Clean, spacious layout with strong grid alignment to ensure visual consistency and easy navigation.
- Minimal border-radius (4px for buttons, 0px for containers) to maintain sharp, clean lines and a modern aesthetic.
- Subtle fade-in and slide-up animations for cards and elements on scroll to create a smooth user experience.
